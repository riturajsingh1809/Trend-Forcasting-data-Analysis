# Trend Forecasting & Demand Analysis

*Developed by Ritu Raj Singh*

## Project Overview

This project focuses on analyzing historical demand trends and forecasting future demand using time-series analysis.

## Tools Used

* *Excel* – Data Cleaning
* *Python (Pandas, NumPy, Statsmodels)* – Data Analysis & Forecasting
* *Tableau* – Visualization & Dashboard

## Project Workflow

1. Data Cleaning in Excel
2. Exploratory Data Analysis using Python
3. Monthly and yearly demand analysis
4. Trend and seasonality analysis
5. Time-based train-validation split
6. Naive baseline comparison
7. Exponential Smoothing forecasting
8. Forecast evaluation using MAE and MAPE
9. Future demand forecasting with uncertainty
10. Tableau dashboard creation

## Key Outputs

* Monthly and yearly demand trends
* Region-wise and category-wise analysis
* Seasonality analysis
* Forecast model comparison
* 12-month future demand forecast
* Forecast uncertainty and confidence range

## Project Files

The repository contains the raw dataset, cleaned dataset, Python analysis results, forecasting notebook, Tableau workbook, and dashboard output.
